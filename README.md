## Run locally

Clone this repository and open `index.html` in a browser. No build step is required.

## Enable GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for the Pages deployment to finish. The intended site address is **https://singhaarvi728.github.io**.

## Project provenance and limitations

- The Hospital Management System, Library Management System, and Stock Price Prediction repositories contain reconstructed portfolio implementations. They are not recovered copies of original bachelor’s source files.
- DataForge is an architecture/documentation showcase. The contribution is documentation; no AWS deployment or infrastructure implementation is claimed.
- The air-quality dashboard reads the committed CSV and stops with an error if the file or required columns are missing. It does not silently substitute synthetic records. The dataset is a static snapshot, not a live feed.
- The bike-rental analysis depends on the original `train.csv` dataset.
- The master's thesis is ongoing; no unfinished experimental results are represented as final findings.

All project READMEs include their own setup instructions and limitations.
