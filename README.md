## Run locally

Clone this repository and open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages

The site is configured to publish from the `main` branch at the repository root. GitHub Pages deployment status is visible in the repository's **Deployments** tab.

## Project provenance and limitations

- The Hospital Management System, Library Management System, and Stock Price Prediction repositories contain reconstructed portfolio implementations. They are not recovered copies of original bachelor’s source files.
- DataForge is an architecture/documentation showcase; the contribution is described as documentation, not deployed infrastructure.
- The air-quality application may contain a synthetic-data fallback. Synthetic examples must not be described as measured real-world findings.
- The bike-rental analysis depends on the dataset committed in its repository.
- The master's thesis is ongoing; no unfinished experimental results are represented as final findings.

All project READMEs include their own setup instructions and limitations.
