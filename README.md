# Aarushi Singh — Portfolio

A responsive static portfolio for GitHub Pages.

## Files
- `index.html` — page content and metadata
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year

## Run locally
Open `index.html` in a browser.

## Enable GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save. GitHub will publish the site at https://singhaarvi728.github.io once deployment completes.

## Project notes
- The air-quality project may generate synthetic sample data when a source CSV is absent. Do not interpret those samples as measured real-world results.
- The bike-sharing analysis requires its original `train.csv` dataset.
- The master's thesis is an ongoing project; results are not presented as completed findings.

This site is plain HTML, CSS and JavaScript and requires no build step.
